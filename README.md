# 🏎️🎨 우리 반 드로잉 레이싱

학생이 그린 자동차 그림이 3D 레이싱카가 되어, 교실 큰 화면에서 함께 달리는 수업용 웹사이트입니다.

- **학생**: 방 코드 + 별명으로 입장 → 그림 사진 올리기 → 자기 기기로 조종
- **교사**: 방 만들기 → 큰 화면에 QR 표시 → 조 편성 → 레이스 중계 → 시상대
- 회원가입·이메일·실명 없이 **방 코드와 별명만** 씁니다.
- 웹사이트는 **Vercel**, 실시간 통신과 저장은 **Supabase** 를 씁니다. 따로 켜 둘 서버가 없습니다.

---

## 수업 당일 체크리스트

### 수업 전 (2분)

1. 프로젝터에 연결한 컴퓨터의 크롬에서 배포 주소(예: `https://3dracing-theta.vercel.app`)를 엽니다. 스피커도 연결해 두면 카운트다운·도착 효과음이 나옵니다.
2. **선생님: 방 만들기** → **교사 코드** 입력 → **방 만들기**.
3. 방 코드(숫자 4개)와 QR 코드가 크게 보입니다.
4. ⚠️ **이 탭이 레이스를 계산합니다.** 수업이 끝날 때까지 닫지 마세요. 잠깐 다른 탭을 봐도 레이스가 계속되도록 만들어 두었지만, 학생들이 보는 화면이니 이 탭을 띄워 두세요. 실수로 닫았다면 같은 컴퓨터·같은 브라우저에서 주소를 다시 열면 학생 명단·조 편성·결과가 이어집니다(달리던 레이스만 처음부터).

### 학생 입장

5. 학생은 QR을 찍거나, 주소로 들어가 **방 코드 + 별명**을 넣습니다. (🎲 버튼이 별명을 골라 줍니다)
6. **그림 올리기**로 종이에 그린 자동차 사진을 올립니다. 올리자마자 그림이 두께 있는 장난감 차가 됩니다.
   - 그림 요령: 옆에서 본 모습, 종이에 크게, 진한 색, 사진은 그림이 화면에 꽉 차게
   - 차 앞뒤가 반대면 **↔ 앞뒤 바꾸기**
   - 그림이 없어도 기본 카트로 달릴 수 있습니다.
7. 큰 화면 대기실에 학생들의 차가 빙글빙글 돌며 나타납니다.
   - 부적절한 그림은 이름 옆 🙈 로 바로 가릴 수 있습니다. ✕ 는 내보내기.

### 레이스

8. 코스·바퀴 수·한 번에 달리는 인원(4·6·8명)을 고릅니다.
9. 인원이 많으면 **🎲 조 편성하기** → 예선 조가 자동으로 나뉩니다. 적으면 바로 **레이스 시작!**
10. **○조 출발!** → 3·2·1 카운트다운 → 학생은 자기 기기에서 조종합니다.
    - 화면 버튼: ◀ ▶ 방향, **출발!** 가속, **멈춤** 브레이크 / 키보드: 방향키 또는 WASD
    - 달리지 않는 조의 기기에는 "📣 지금 달리는 친구들"이 나옵니다. 순위는 큰 화면에서 봅니다.
    - 효과음은 큰 화면에서만 납니다. 끄려면 **🔊 소리 켜짐** 버튼.
11. 결과 화면 → **다음으로 ▶** → 예선이 모두 끝나면 결승 진출자가 자동으로 정해집니다. (각 조 상위권 + 남는 자리는 기록 순)
12. 결승이 끝나면 **🏆 시상대 보기**.

### 수업 후

13. **방 닫기**를 누르면 그 방의 그림과 3D 모델이 바로 삭제됩니다.
14. 또는 `관리자` 화면의 **🗑 수업 끝! 전체 삭제**.
15. 깜빡해도 정해진 시간(기본 24시간) 뒤 자동으로 삭제됩니다. 4시간 동안 쓰지 않은 방도 자동으로 닫힙니다.

### 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 학생이 "선생님 화면이 응답하지 않아요" | 교사 화면 탭이 열려 있는지 확인. 방 코드가 맞는지 확인 |
| 학생 화면이 "선생님 화면을 기다리는 중" | 교사 화면을 새로고침했거나 닫았을 때 나옵니다. 교사 화면을 다시 열면 이어집니다 |
| 레이스 중 한 학생 차가 혼자 직진 | 그 기기 인터넷이 끊긴 것. 마지막으로 누르던 대로 달리다가, 다시 연결되면 조종이 돌아옵니다 |
| 효과음이 안 나요 | 교사 화면에서 버튼을 한 번 누른 뒤부터 납니다(브라우저 규칙). **🔇 소리 꺼짐**이면 눌러서 켜기 |
| 화면 위에 "인터넷 연결이 끊겼어요" | 자동으로 다시 연결됩니다. 새로고침해도 같은 별명으로 이어집니다 |
| 학교 인터넷에서 아예 안 열림 | `*.vercel.app` 과 `*.supabase.co` 가 학교 방화벽에서 막혀 있는지 정보 담당 선생님께 확인 |
| 크롬북에서 느림 | 버벅이면 화면 해상도를 자동으로 낮춥니다(조금 흐려 보일 수 있음). 그래도 느리면 다른 탭을 닫고, 한 번에 달리는 인원을 6명으로 줄여 보세요 |
| 폰에서 버튼이 안 눌려요 | 화면을 가로로 돌리면 버튼이 더 커집니다. 키보드가 있으면 방향키도 됩니다 |
| 그림 배경이 안 지워짐 | 흰 종이에 그리고, 책상이 안 보이게 가까이 찍기. 안 지워져도 그림 전체가 차가 됩니다 |

## 배포 (Vercel)

1. https://vercel.com 에 **GitHub 계정으로** 로그인합니다.
2. **Add New… → Project** → `yoonyoons/3Dracing` 저장소 옆 **Import**.
3. 설정은 `vercel.json` 에서 자동으로 읽습니다. **Root Directory 는 비워 두거나(`./`) `client` 로 두세요.** (`shared` 나 `supabase` 를 고르면 안 됩니다.) 나머지는 바꾸지 말고 **Deploy**.
4. 1~2분 뒤 `https://<프로젝트이름>.vercel.app` 주소가 생깁니다. 끝!

- Vercel 에 넣어야 하는 **비밀 값은 없습니다.** Supabase 주소와 공개용 키는 `client/src/net/supabase.ts` 에 들어 있습니다(브라우저에 공개돼도 되는 값).
- 이 저장소에 푸시하면 Vercel 이 자동으로 다시 배포합니다.
- 교사 코드와 관리자 비밀번호는 Supabase 데이터베이스에 암호화되어 저장되어 있고, **관리자 화면 → ⚙️ 설정**에서 바꿀 수 있습니다.

### 개발

```bash
npm install
```

```bash
npm run dev
```

`http://localhost:5173` 에서 열립니다(배포판과 같은 Supabase 에 연결됩니다). 타입 검사는 `npm run typecheck`, 배포용 빌드는 `npm run build`.

| 시험 | 명령 | 내용 |
|---|---|---|
| 단위 테스트 | `npm test` | 물리·트랙, 조 편성, 입력 처리, 별명 금칙어, 그림 배경 제거, GLB 다듬기 |
| 교실 흐름 전체 | `E2E_TEACHER_CODE=<교사코드> ./scripts/e2e.sh` | 교사 1 + 학생 3: 입장, 그림, 새로고침, 레이스 중 끊김·새로고침, 결과, 시상대, 내보내기, 방 닫기 (실제 Supabase 사용) |
| 30명 대기실 | `E2E_TEACHER_CODE=<교사코드> node scripts/load-lobby.cjs 30` | 가짜 학생 30명 입장, 교사 화면 fps, 실시간 메시지 수 (미리보기 서버를 먼저 켜 두기) |
| 저사양 성능 | `node scripts/perf.cjs 4` | CPU 4배 느리게 해서 레이스 화면 fps (미리보기 서버를 먼저 켜 두기) |

미리보기 서버: `npm run build` 후 `cd client && npx vite preview --port 4173 --outDir ../dist`

## 3D 변환 방식

관리자 화면 **⚙️ 설정 → 3D 변환 모드**에서 고릅니다.

| 모드 | 설명 |
|---|---|
| **사전 생성** (기본, B 모드) | 교사가 Higgsfield 에서 미리 만든 GLB 를 관리자 화면에서 학생 그림과 짝지어 올립니다 |
| **연습용 샘플 3D** (mock) | 크레딧 없이, 그림을 올리면 6초 뒤 그림 색으로 칠한 샘플 3D 차가 붙습니다 |

어느 모드든 3D 모델이 없거나 실패하면 **그림 차체**(그림 윤곽에 두께를 준 차)로 바로 달립니다.

**실시간(A 모드)이 없는 이유:** 2026년 11월 확인 기준 Higgsfield 공개 API 에는 3D(GLB) 모델이 없습니다. 또 Vercel + Supabase 구조에는 API 비밀 키를 숨겨 둘 서버가 없습니다. 나중에 쓰려면 Supabase Edge Function 에 키를 넣고 변환기를 호출하도록 추가해야 합니다.

### B 모드 사용법 (관리자 화면 `/admin`)

1. 학생 그림마다 **⬇ 그림 받기** → 배경이 정리된 흰 배경 PNG (`별명.png`).
2. Higgsfield 에서 그 그림으로 3D 모델을 만들어 GLB 로 받습니다.
3. **⬆ GLB 올리기**로 짝지어 올리거나, 파일 이름을 `별명.glb` 로 해서 **📦 GLB 여러 개 올리기**.
4. 관리자 브라우저에서 자동으로 다듬은 뒤 저장합니다: 길이 기준 크기 맞춤, 바닥 높이 맞춤, 긴 방향을 앞뒤로 정렬, 폴리곤 12,000개·텍스처 512px 로 경량화. 다듬은 뒤 6MB 이하여야 합니다.
5. 앞뒤가 반대면 **↔ 앞뒤**.

Higgsfield 크레딧 참고(테스트 시점 견적): `sam_3_3d` 1크레딧(측면 그림은 납작한 판으로 나옴), `tripo_h3_1_image_to_3d` 9, `hunyuan3d_v3` LowPoly 18, Meshy 계열 30~38.

## 개인정보와 안전

- 저장하는 것: **별명, 방 코드, 정리된 그림, 3D 모델**뿐. 회원가입·이메일·실명 입력이 없습니다.
- 별명은 금칙어 필터를 거치고 8글자로 제한됩니다. 화면에서 "진짜 이름 말고 별명"을 안내합니다.
- 사진은 **학생 기기 안에서** 배경을 지우고 다시 그린 뒤 올립니다. 원본 사진과 촬영 위치 같은 사진 정보는 전송되지 않습니다.
- 삭제: 방 닫기 시 즉시, 관리자 화면에서 일괄, 그리고 보관 시간이 지나면 자동(Supabase pg_cron, 10분마다).
- 데이터는 API 로 노출되지 않는 `race` 스키마에 있고, 브라우저는 교사 코드·관리자 비밀번호·학생 비밀 값을 확인하는 데이터베이스 함수(`public.race_*`)로만 접근합니다. 비밀번호를 8번 틀리면 1분간 막힙니다.
- 외부 CDN 을 쓰지 않습니다(폰트·QR·3D 라이브러리 모두 번들에 포함).

**알아 둘 한계:** 실시간 채널은 공개 채널이라, 개발자 도구를 다룰 줄 아는 학생이라면 방 코드로 가짜 방 상태를 보내 화면을 어지럽힐 수 있습니다(다른 학생의 조종·그림은 비밀 값이 있어야 바꿀 수 있습니다). 수업용으로는 충분하지만, 문제가 생기면 방을 닫고 새로 여세요.

## 구조

```
client/   Vite + React + Three.js(react-three-fiber): 학생/교사/관리자/연습 화면, Supabase 연결
shared/   트랙, 아케이드 물리, 방·조 편성·레이스 계산, 그림 배경 제거, GLB 후처리 (+ 테스트)
supabase/ 데이터베이스 구조와 함수 (migrations)
```

- **교사 화면 = 레이스 서버.** 교사 브라우저가 초당 30번 물리를 계산하고, 달리는 인원에 맞춰 초당 4~10번 상태를 보냅니다. 학생 기기는 입력만 보냅니다. 다른 차는 두 상태 사이를 보간해 부드럽게 그리고, 내 차는 같은 물리 코드로 미리 움직인 뒤 교사 화면 값에 조금씩 맞춥니다.
- **Supabase 무료 플랜 한도**에 맞춰 설계했습니다: 실시간 메시지 초당 100개, 한 달 200만 개. 그래서 한 번에 달리는 인원은 최대 8명입니다. 30명 반이 한 시간 수업하면 한 달 한도의 약 5%를 씁니다. 더 많이 쓰려면 Supabase Pro 로 올리면 됩니다.
- **트랙**: 타원(⭐), 8자(⭐⭐), 꼬불꼬불(⭐⭐⭐). `shared/src/track.ts` 에 곡선 식을 추가하면 새 코스가 됩니다.
- **인원**: 한 방 최대 30명.
