# 🏎️🎨 우리 반 드로잉 레이싱

학생이 그린 자동차 그림이 3D 레이싱카가 되어, 교실 큰 화면에서 함께 달리는 수업용 웹사이트입니다.

- **학생**: 방 코드 + 별명으로 입장 → 그림 사진 올리기 → 자기 기기로 조종
- **교사**: 방 만들기 → 큰 화면에 QR 표시 → 조 편성 → 레이스 중계 → 시상대
- 회원가입·이메일·실명 없이 **방 코드와 별명만** 씁니다.

---

## 수업 당일 체크리스트

### 수업 전 (5분)

1. 교사 노트북을 **학생 기기와 같은 와이파이**에 연결합니다.
2. 터미널에서 서버를 켭니다.
   ```bash
   npm start
   ```
3. 터미널에 나온 내용을 확인합니다.
   - `학생 기기에서: http://192.168.x.x:3000` ← 학생이 접속할 주소
   - `관리자 비밀번호: ....` ← 관리자 화면에 필요
4. 노트북 브라우저(크롬)에서 `http://localhost:3000` → **선생님: 방 만들기** → **방 만들기**.
5. 이 화면을 프로젝터에 띄웁니다. 방 코드(숫자 4개)와 QR 코드가 크게 보입니다.

### 학생 입장

6. 학생은 QR을 찍거나, 주소로 들어가 **방 코드 + 별명**을 넣습니다. (🎲 버튼이 별명을 골라 줍니다)
7. **그림 올리기**로 종이에 그린 자동차 사진을 올립니다. 올리자마자 그림이 두께 있는 장난감 차가 됩니다.
   - 그림 요령: 옆에서 본 모습, 종이에 크게, 진한 색, 사진은 그림이 화면에 꽉 차게
   - 차 앞뒤가 반대면 **↔ 앞뒤 바꾸기**
   - 그림이 없어도 기본 카트로 달릴 수 있습니다.
8. 큰 화면 대기실에 학생들의 차가 빙글빙글 돌며 나타납니다.
   - 부적절한 그림은 이름 옆 🙈 로 바로 가릴 수 있습니다. ✕ 는 내보내기.

### 레이스

9. 코스·바퀴 수·한 번에 달리는 인원(4~10명)을 고릅니다.
10. 인원이 많으면 **🎲 조 편성하기** → 예선 조가 자동으로 나뉩니다. 적으면 바로 **레이스 시작!**
11. **○조 출발!** → 3·2·1 카운트다운 → 학생은 자기 기기에서 조종합니다.
    - 화면 버튼: ◀ ▶ 방향, **출발!** 가속, **멈춤** 브레이크 / 키보드: 방향키 또는 WASD
    - 달리지 않는 조는 큰 화면을 보며 응원합니다.
12. 결과 화면 → **다음으로 ▶** → 예선이 모두 끝나면 결승 진출자가 자동으로 정해집니다.
    (각 조 상위권 + 남는 자리는 기록 순)
13. 결승이 끝나면 **🏆 시상대 보기**.

### 수업 후

14. **방 닫기**를 누르면 그 방의 그림과 3D 모델이 바로 삭제됩니다.
15. 또는 `관리자` 화면의 **🗑 수업 끝! 전체 삭제**를 누릅니다.
16. 깜빡해도 24시간 뒤 자동으로 삭제됩니다(`RETENTION_HOURS`).

### 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 학생 기기에서 주소가 안 열림 | 같은 와이파이인지 확인. 노트북 방화벽에서 Node.js 허용. 학교 와이파이가 기기끼리 통신을 막으면(AP 격리) 교사 휴대폰 핫스팟을 쓰거나 인터넷 배포(아래)를 이용 |
| 화면 위에 "연결이 끊겼어요" | 자동으로 다시 연결됩니다. 새로고침해도 같은 별명으로 이어집니다 |
| 교사 화면을 실수로 닫음 | 같은 브라우저에서 `/host` 를 다시 열면 방이 이어집니다 |
| 크롬북에서 느림 | 다른 탭을 닫고, 한 번에 달리는 인원을 6명으로 줄여 보세요 |
| 그림 배경이 안 지워짐 | 흰 종이에 그리고, 책상이 안 보이게 가까이 찍기. 안 지워져도 그림 전체가 차가 됩니다 |

## 설치

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm run build
```

```bash
npm start
```

설정을 바꾸려면 `.env.example` 을 `server/.env` 로 복사해 고칩니다. 아무 설정 없이도 동작합니다.

개발할 때는 `npm run dev` (서버 3000 + Vite 5173, 저장하면 바로 반영). 테스트는 `npm test`, 타입 검사는 `npm run typecheck`.

## 3D 변환 방식

그림 → 3D 모델(GLB) 변환은 `CarGenerator` 인터페이스(`server/src/generators/types.ts`) 뒤에 있어 제공자를 바꿀 수 있습니다.

| 모드 (`GENERATOR`) | 설명 |
|---|---|
| `pregenerated` (기본, **B 모드**) | 교사가 Higgsfield 에서 미리 만든 GLB 를 관리자 화면에서 학생 그림과 짝지어 올립니다 |
| `mock` | 개발용. 크레딧 없이 몇 초 뒤 샘플 3D 차를 돌려줍니다 |
| `higgsfield` (**A 모드**) | 서버가 실시간으로 호출. **아직 검증되지 않았습니다**(아래 참고) |

어느 모드든 변환 전·변환 중·실패 시에는 **그림 차체**(그림 윤곽에 두께를 준 차)로 바로 달립니다. 변환이 `GEN_TIMEOUT_SEC`(기본 180초)을 넘겨도 마찬가지입니다.

### 왜 B 모드가 기본인가

2026년 11월 확인 기준, Higgsfield **공개 API**(`api.higgsfield.ai`)에는 이미지·영상 모델만 있고 3D 모델이 없습니다. 3D 변환은 Higgsfield 웹/앱과 MCP 에서만 됩니다. 그래서 웹서버가 수업 중에 직접 호출할 방법이 없습니다.

`server/src/generators/higgsfield.ts` 는 공개 API 의 공통 방식(제출 → `request_id` → 상태 폴링)에 맞춘 틀이며, 3D 모델이 API 에 추가되면 `HIGGSFIELD_3D_MODEL` 등을 채워 시험해 볼 수 있습니다. 같은 모델(Meshy, Tripo 등)을 공개 API 로 제공하는 다른 서비스를 쓰려면 `CarGenerator` 를 하나 더 구현하면 됩니다.

### B 모드 사용법 (관리자 화면)

1. `http://localhost:3000/admin` → 비밀번호 입력.
2. 학생 그림마다 **⬇ 그림 받기** → 배경이 정리된 흰 배경 PNG (`별명.png`).
3. Higgsfield 에서 그 그림으로 3D 모델을 만들어 GLB 로 받습니다.
4. **⬆ GLB 올리기**로 짝지어 올리거나, 파일 이름을 `별명.glb` 로 해서 **📦 GLB 여러 개 올리기**.
5. 서버가 자동으로 후처리합니다: 길이 기준 크기 맞춤, 바닥 높이 맞춤, 긴 방향을 앞뒤로 정렬, 폴리곤 12,000개·텍스처 512px 로 경량화.
6. 앞뒤가 반대면 **↔ 앞뒤**.

Higgsfield 크레딧 참고(테스트 시점 견적): `sam_3_3d` 1크레딧(측면 그림은 납작한 판으로 나옴), `tripo_h3_1_image_to_3d` 9, `hunyuan3d_v3` LowPoly 18, Meshy 계열 30~38.

## 개인정보와 안전

- 수집하는 것: **별명, 방 코드, 올린 그림**뿐. 회원가입·이메일·실명 입력이 없습니다.
- 별명은 금칙어 필터를 거치고 8글자로 제한됩니다. 화면에서 "진짜 이름 말고 별명"을 안내합니다.
- 올린 사진은 서버에서 다시 그려 저장하므로 **촬영 위치 등 사진 정보가 남지 않습니다.** 원본 사진은 저장하지 않고, 배경을 지워 잘라 낸 그림만 저장합니다.
- 삭제: 방 닫기 시 즉시, 관리자 화면에서 일괄, 그리고 `RETENTION_HOURS` 뒤 자동.
- API 키와 비밀번호는 서버 환경변수(`.env`)에만 있고 브라우저로 보내지 않습니다.
- 외부 CDN 을 쓰지 않습니다(폰트·QR·3D 라이브러리 모두 번들에 포함).
- WebSocket 이 막힌 네트워크에서는 Socket.IO 가 자동으로 HTTP 폴링으로 동작합니다.

## 저장소: Supabase (선택)

기본은 이 컴퓨터의 `data/` 폴더입니다. 인터넷에 배포할 때는 Supabase 를 쓰세요.

- 프로젝트 `drawing-racing` (서울 리전)에 `cars` 테이블과 비공개 버킷 `race-assets` 가 준비되어 있습니다. (`supabase/migrations/0001_init.sql`)
- `server/.env` 에 아래 두 값을 넣으면 켜집니다.
  ```
  SUPABASE_URL=https://jucuqdiihcyqpjbttovf.supabase.co
  SUPABASE_SERVICE_KEY=sb_secret_...
  ```
  키는 Supabase 대시보드 → Project Settings → API Keys 의 **secret** 키입니다. 절대 깃에 올리지 마세요.
- 테이블은 RLS 가 켜져 있고 정책이 없어 서버의 secret 키로만 접근됩니다. 브라우저는 Supabase 에 직접 접속하지 않고 우리 서버를 거칩니다.

> Supabase 저장 코드는 작성되어 있지만, secret 키가 없어 실제 연결 테스트는 하지 못했습니다. 키를 넣은 뒤 그림 한 장을 올려 확인해 주세요.

## 배포

| 방법 | 비용 | 특징 |
|---|---|---|
| **교사 노트북 + 교실 와이파이** (추천) | 무료 | 설치만 하면 끝. 학교 방화벽 영향이 가장 적음 |
| **Render.com** | 무료 플랜 | `render.yaml` 포함. 15분간 접속이 없으면 잠들어 첫 접속이 느림 → 수업 전에 미리 열어 두기. Supabase 저장소 필요 |
| **Docker** | 서버에 따라 | `docker build -t drawing-racing . && docker run -p 3000:3000 drawing-racing` |

인터넷에 배포하면 `PUBLIC_URL` 과 `ADMIN_PASSWORD` 를 꼭 설정하세요.
서버 한 대가 방 상태를 메모리에 갖고 있으므로 **인스턴스는 1개**로 운영합니다.

## 구조

```
shared/   서버·브라우저 공용: 트랙, 아케이드 물리, 통신 규격, 별명 검사
server/   Express + Socket.IO: 방·조 편성·레이스 시뮬레이션, 그림 처리, 3D 변환기, 저장소, 관리자 API
client/   Vite + React + Three.js(react-three-fiber): 학생/교사/관리자/연습 화면
```

- **네트워크**: 서버가 초당 30번 물리를 계산하고 15번 상태를 보냅니다. 브라우저는 입력만 보냅니다. 다른 차는 두 상태 사이를 보간해 부드럽게 그리고, 내 차는 같은 물리 코드로 미리 움직인 뒤 서버 값에 조금씩 맞춥니다.
- **트랙**: 타원(⭐), 8자(⭐⭐), 꼬불꼬불(⭐⭐⭐). `shared/src/track.ts` 에 곡선 식을 추가하면 새 코스가 됩니다.
- **인원**: 한 방 최대 30명, 한 번에 달리는 인원 2~10명.
- drei 는 쓰지 않았습니다. 일부 기능이 외부 CDN 에서 파일을 받아 오기 때문입니다.
